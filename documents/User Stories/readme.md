Sprint 1 – Prototypefase (UI-validatie)

User story – Prototype

As a potential user,
I want to explore a clickable prototype of the Vicaris Village application,
so that I can understand the main navigation and intended user flows before any real data is processed.

Acceptance criteria

The prototype displays the main navigation (Suggestie, Polls, Results, Login)

Core buttons such as “Stem nu” and “Artiest suggereren” are clickable

No backend or data persistence is required

Users can navigate between pages without errors

Feedback from test users is collected and documented



Sprint 2 – First version (core MVP)

User story – First implementation

As a user,
I want to view available polls and submit a vote or suggestion,
so that I can actively participate in the Vicaris Village selection process.

Acceptance criteria

Polls are retrieved from the database and displayed to the user

Users can submit a vote via the polling interface

Users can suggest an artist using a form

Votes and suggestions are stored persistently

No admin functionality or advanced result visualization is required

Result visibility is limited and non-graphical



Sprint 3 – Final version (final MVP)

User story – Improved MVP (user)

As a user,
I want to view clear and structured poll results and submitted suggestions,
so that I can understand the collective preferences of the community.

Acceptance criteria

Poll results are dynamically calculated and displayed

Suggested artists are shown in an overview

Navigation across all main pages works reliably

The application is deployed and accessible online

User feedback from earlier sprints is incorporated into the final version



Sprint 3 – Admin functionality

User story – Administration

As an admin,
I want to manage artists, editions and polls,
so that the Vicaris Village application remains accurate, up to date and scalable for future events.

Acceptance criteria

Admin can add, edit and remove artists

Admin can create and manage editions

Admin can activate or deactivate polls per edition

Changes are immediately visible to end users

Access is restricted to admin users only
